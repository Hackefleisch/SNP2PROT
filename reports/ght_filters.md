This is the `GHT_PLAN.md` §5 decision measured rather than argued: several widths were used because real DBD motifs run roughly 6-20 bp and a single-layer convolution followed by a global maximum has no composition across layers, so one width caps what a filter can express. If every match landed at one width the bank would be wasted.
